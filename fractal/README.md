# Fractal Renderer

Dependency-free interactive fractal renderer built with HTML, CSS, and vanilla JavaScript.

## Features

- Mandelbrot, Julia, Burning Ship, Tricorn, Multibrot Cubic, Celtic Mandelbrot, and Buffalo fractals
- Presets for notable regions
- Expanded palette library with 12 color schemes
- Mouse-wheel zoom, drag pan, and double-click zoom
- Adjustable iterations, escape radius, palette, coloring strength, and resolution scale
- PNG export

## Run

Open [index.html](./index.html) directly in a browser, or serve the folder with any static file server.

## Notes

- Higher iteration counts and resolution scales produce better detail but take longer to render.
- Julia mode enables direct control of the complex constant.
