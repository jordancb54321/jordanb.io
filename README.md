# Static Portfolio

This is a build-free portfolio site made with plain HTML and CSS for maximum speed, stability, and hosting simplicity.

## Files

- `index.html` contains the content and structure.
- `styles.css` contains the full visual design.

## Customize

1. Replace `Your Name`, `hello@example.com`, and social links in `index.html`.
2. Update the project cards with your real work.
3. Change the page title and meta description for your name and focus.

## Deploy

Upload the folder to any static host such as GitHub Pages, Netlify, Cloudflare Pages, Vercel static hosting, or a traditional web server.
