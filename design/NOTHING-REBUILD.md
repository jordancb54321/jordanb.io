# November 2026 redesign

The site uses a new presentation built from scratch. The existing JavaScript tool engines, saved study data format, routes and Cloudflare worker remain the functional foundation.

The visual direction takes cues from Nothing: a neutral paper background, near-black type and surfaces, dot-matrix details, a precise grid, and one red accent. Plain sans-serif text does most of the work. The dot face is reserved for the wordmark and study counters.

The homepage starts with a compact identity and a selectable, code-drawn preview of the four projects. A consistent project index replaces the previous mosaic. Short factual biography and contact sections complete the page. There are no autoplaying effects, decorative status claims, invented statistics or promotional slogans.

The project pages share a compact header and concise title/action area. The fractal canvas precedes its settings. Chess keeps its board prominent; sorting gives equal space to the selected algorithms. The study deck uses monochrome metrics, tab navigation and a simple flashcard surface. Project thumbnails are fresh captures of these redesigned tools.

All fonts and scripts are served locally. Preview selection is progressive enhancement; project links work without JavaScript. Keyboard focus and reduced-motion preferences are supported. No additional runtime dependencies.
