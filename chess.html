Custom JavaScript build

Chess engine demo with a browser-first UI.

This page uses chess.js for legal move generation and a custom minimax engine written in plain JavaScript. The board UI is rendered with chessboard.js so the page stays static and easy to host.

Engine profile

  • Minimax search with alpha-beta pruning and move ordering
  • Quiescence search for tactical capture sequences
  • Material, piece-square, pawn-structure, and development scoring
  • Web Worker search so deeper analysis does not block the board
  • Adjustable search depth and live game status
